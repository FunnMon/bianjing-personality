# 素材和史料

- `src/qingming.webp` 是张择端《清明上河图》的虹桥局部，从维基共享资源获取公版复制品后缩放并压为 WebP。首页使用响应式裁切，保存结果图使用同一原图的完整局部。作品现藏故宫博物院。 [维基共享资源原文件](https://commons.wikimedia.org/wiki/File:Along_the_River_During_the_Qingming_Festival_(detail_of_original).jpg) · [故宫博物院藏品资料](https://www.dpm.org.cn/collection/paint/228226.html)
- `share.jpg` 是据实际页面生成的首页预览图，所含画作为上述公版局部。
- `src/cover.woff2` 为 Google Fonts 提供的 Noto Serif SC 600 字符子集。SIL Open Font License 1.1 随源文件和网页分发。 [Google Fonts](https://fonts.google.com/noto/specimen/Noto+Serif+SC) · [许可文件](OFL-NotoSerifSC.txt)
- 情境参考包括孟元老《东京梦华录》卷二州桥夜市、卷三相国寺内万姓交易和雇觅人力、卷四杂赁修整杂货和食店。角色的资产和具体经历为此次测评创作。 [古籍原文及目录](https://www.shidianguji.com/book/NGJ89241199901998071179/chapter/1lnokndxi81kw)
- `src/motion.css` 与 `src/motion.js` 取自本任务调用的 design-taste-frontend 技能，保持原文件内容。
