# 你在北宋汴京，会是哪一层人？

一份中文娱乐测评。12 道题从现代日常行为采集做事倾向，并匹配北宋徽宗年间汴京市井的 8 种虚构生计原型。

## 打开和构建

使用 Node 22 或更新版本运行 `node scripts/build-pages.mjs`，然后在现代浏览器打开 `site/index.html`。图片、标题字体和脚本均内嵌，答题和生成结果图可离线完成。浏览器允许本地存储时可以在同一设备续测。

编辑 `src/` 后运行相同命令重新构建，无需安装依赖。`node scripts/verify-scoring.mjs` 检查可达的评分组合与结果引文。GitHub Actions 构建后发布 `site/`。

## 结果口径

12 道题平均覆盖四组倾向：专技与渠道、流程与临场、保底与试水、独立与组织。各组分数寻找最接近的原型。结果中的两条作答线索引用当前答案，相同的答题组合得到一致结果。

生计阶层由收入来源、可调动资源和经营依托描述。受雇谋生、自营谋生、有铺有本、富足经营户是本测评使用的描述性分组。共同设定是普通家底，能接触对应行当。职业原型和结果解读均为创作。
